1. 프로그램 소개와 화면 구성

OmniDT SE (Spatial Editor)는 CAD(DXF) 도면의 설비(장비) 블록을 PostgreSQL/PostGIS 서버에 저장해 두고, 2D 화면에서 조회·편집하며 여러 사람이 같은 데이터를 함께 쓰는 프로그램입니다.

  • 블록 객체: DXF의 INSERT 하나가 편집 가능한 객체 하나입니다. 선이 여러 개여도 하나로 선택·이동·회전됩니다.
  • 레이어: 객체를 묶는 이름입니다(예: Equipment). 보이기/숨기기, 색상 설정, 편집 대상 선택의 단위입니다.
  • 조회 모드 / 편집 모드: 평소에는 조회 모드이고, 편집 모드에서만 객체를 바꿀 수 있습니다. 편집 내용은 저장해야 서버에 반영됩니다.
이 매뉴얼 보기프로그램 안에서 F1 또는 Help → User manual (PDF)를 누르면 이 매뉴얼의 PDF 판이 열립니다.

2. 서버 연결과 로그인

2.1 서버 연결

  1. 프로그램을 시작하면 저장된 연결 정보로 자동 접속합니다. 실패하면 서버 연결 창이 뜹니다. 툴바 서버로도 열 수 있습니다.
  2. Host, Port, Database, Username, Password를 입력하고 접속을 시험합니다.
  3. 성공하면 정보가 저장되어 다음 실행부터 자동으로 연결됩니다. 연결 상태는 상태 표시줄 왼쪽의 점(초록=연결됨)으로 확인합니다.
[ 화면 캡처 1 자리 ]
서버 연결 창

2.2 로그인

  1. 연결 후 로그인 창이 나옵니다. 위쪽에는 프로그램 그림, 아래쪽에 ID와 Password 입력란이 있습니다.
  2. ID/Password를 입력하고 Log in을 누릅니다. 마지막으로 쓴 ID는 기억됩니다.
  3. 사용자가 한 명도 없는 새 서버에서는 첫 관리자 만들기 화면(Name, Confirm password 추가)이 나옵니다.

3. 데이터 불러오기

3.1 DXF 입력 (Import)

  1. 툴바 입력을 누릅니다. (import.dxf 권한 필요)
  2. 서버에 이미 같은 DXF 데이터가 있으면 삭제하고 다시 넣을지 묻습니다.
  3. 진행 상황이 표시되고, 끝나면 DXF와 DB의 수량이 비교되어 기록됩니다. 진행 중에는 중단으로 취소할 수 있습니다(저장 내용은 롤백).
장비만 가져오기장비를 켜고 입력하면 Equipment 레이어의 블록(INSERT)만 객체로 가져옵니다. 다른 레이어와 낙서 같은 선은 제외됩니다.
현재 제한입력하는 DXF 파일이 정해진 경로(data\SmartLayout.dxf)로 고정되어 있습니다. 파일 선택 창은 아직 없습니다. 제거는 Import한 데이터를 모두 지우며 되돌릴 수 없습니다.

3.2 레이어 선택 불러오기

시작하면 레이어 목록만 먼저 읽고, Select layers to load 창에서 화면에 불러올 레이어를 고릅니다. 선택은 저장되어 다음에도 유지됩니다. 나중에 바꾸려면 레이어 패널 헤더의 불러오기 버튼(또는 Layer 메뉴 → Load layers…)을 쓰고, 서버의 최신 데이터를 다시 받으려면 새로고침을 누릅니다.

5. 객체 선택과 속성 확인

조회 모드에서 2D 뷰의 객체를 클릭하면 선택됩니다. 블록 객체는 어느 선을 눌러도 블록 전체가 하나로 선택되어 윤곽이 표시됩니다. 선택하면 속성 패널에 종류, 형상, 좌표계, 속성 표가 나옵니다. 빈 곳을 누르면 선택이 풀립니다. 숨긴 레이어의 객체는 선택되지 않습니다.

조회 모드의 선택은 1개조회 모드에서는 한 번에 하나만 선택됩니다. 여러 개를 한꺼번에 선택하려면 편집 모드(8장)를 사용하세요.

선택 강조 모양 바꾸기

설정 → General → Selection outline에서 선택 테두리 색상(팔레트·RGB·Hex)과 두께(0.5~8 px)를 정합니다. 기본값은 노란색 1.5 px입니다. 설정 창의 미리보기로 확인한 뒤 OK를 누르면 즉시 반영됩니다.

이름 변경 주의이름은 서버의 모든 객체에 적용되며 다른 사용자에게도 알려집니다. 이미 있는 이름(대소문자만 달라도 같은 이름)은 쓸 수 없습니다. 편집 모드 중에는 바꿀 수 없고, drawing.edit 권한이 필요합니다.

6.3 레이어 삭제

레이어를 선택하고 레이어 패널 헤더의 삭제 버튼(또는 우클릭 → Delete this layer…)을 누르면 확인 창(기본 선택 “아니오”)이 나옵니다. 확인하면 그 레이어의 모든 객체가 서버에서 삭제됩니다.

되돌릴 수 없음drawing.delete 권한이 필요하며, 편집 모드 중에는 실행되지 않습니다. 삭제한 레이어는 복구할 수 없으니 필요하면 먼저 DXF로 내보내 두세요.

7. 편집 모드·저장

7.1 편집 모드 시작과 끝

  1. 툴바 편집을 누릅니다. 현재 보이는 모든 레이어가 편집 대상입니다. 한 레이어만 편집하려면 그 레이어의 색 사각형을 누릅니다.
  2. 편집 모드에서는 커서가 십자 모양이 되고, 객체 외곽이 점선으로 표시됩니다. 편집 대상 레이어의 원래 그림은 숨겨져 잔상이 남지 않습니다.
  3. 끝낼 때는 편집을 한 번 더 눌러 나갑니다. 저장하지 않은 변경은 취소로 버리고 나갑니다.
편집 모드의 조건서버에 연결되어 있고 drawing.edit 권한이 있어야 합니다. 편집 중에는 레이어 새로고침·불러오기·이름 변경·삭제가 막힙니다(저장 또는 취소 후 가능).

7.2 저장과 충돌 처리

  • 저장 후에도 편집 화면이 유지됩니다. 확대·화면 위치, 숨긴 레이어, 편집 모드와 편집 중인 레이어가 그대로이고, 서버에 저장된 데이터가 다시 표시됩니다. 선택과 Undo/Redo 이력만 비워집니다.
  • 저장 또는 Ctrl+S — 이동·회전·추가·삭제가 한 번에 저장됩니다. 중간에 오류가 나면 전부 취소됩니다.
  • 내가 읽은 뒤 다른 사람이 같은 객체를 바꿨다면, 그 객체는 덮어쓰지 않고 번호를 알려 줍니다. 나머지는 정상 저장됩니다.
  • 장비가 서로 겹쳐 있으면 저장되지 않습니다.

7.3 자동 저장

설정 → General → Auto-save edits를 켜고 간격(1~120분)을 정하면, 편집 모드에서 그 간격마다 자동으로 저장됩니다. 저장 뒤 편집 모드가 이어지고(수동 저장과 같음) 선택은 해제됩니다. 장비가 겹쳐 있거나 충돌이 있으면 자동 저장은 건너뜁니다.

7.4 다른 사용자의 변경 알림

다른 사용자가 내가 불러온 레이어를 저장하면 “서버 데이터가 변경되었습니다. 갱신하시겠습니까?” 창이 뜹니다(누가, 어느 레이어를, 몇 개).

  • 예: 그 레이어를 다시 불러옵니다. 줌 위치와 숨긴 레이어는 유지됩니다.
  • 아니오: 상태 표시줄에 “갱신 대기 (N건)”로 남습니다. 그것을 누르면 다시 확인할 수 있습니다.
  • 편집 모드 중에는 묻지 않고, 저장하거나 취소한 뒤에 묻습니다. 내가 저장한 변경은 알리지 않습니다.

범위 선택 규칙장비(블록 객체)는 외곽선이 사각형에 닿기만 해도 선택됩니다. 레이어 전체 외곽선처럼 큰 일반 객체는 사각형 안에 완전히 들어올 때만 선택되어, 큰 외곽선이 딸려 오는 일을 막습니다.
[ 화면 캡처 5 자리 ]
범위 선택 중인 2D 뷰 (파란 점선 사각형, 선택된 장비의 노란 점선)

여러 객체를 선택하면 속성 패널에 “N objects selected”가 표시되고, 아래 9장의 모든 동작이 선택된 전체에 한꺼번에 적용됩니다.

9. 이동 · 회전 · 복제 · 삭제 · 그룹

9.1 이동

  • 마우스: 선택된 객체 중 아무거나 끌어서 놓습니다. 선택된 모든 객체가 함께 움직입니다.
  • 키보드: Ctrl+←→↑↓. 한 번에 1 단위, 격자 버튼을 켜면 10 단위(한 칸)씩, Ctrl+Shift+방향키는 10배씩 움직입니다.
  • 이동하면 속성 패널의 삽입점(block_insert_x/y)도 같이 바뀝니다.

9.2 회전

툴바 시계 / 반시, 선택 객체 위의 금색 핸들 클릭, 또는 키 r(시계) / Shift+R(반시계). 한 번에 90°이며, 여러 개를 선택했으면 선택 전체의 중심을 기준으로 함께 돕니다. 회전각(block_rotation_deg)은 0~360°로 기록됩니다.

9.3 복제와 삭제

  • 복제 Ctrl+D: 복사본이 약간 옆에 생기고 복사본들이 새 선택이 됩니다. 바로 끌어서 제자리에 놓으세요. 복사본은 저장할 때 서버에 추가됩니다.
  • 삭제 Del: 삭제 표시가 되고 저장하면 서버에서 지워집니다(drawing.delete 권한 필요). 저장 전에는 Undo로 되돌릴 수 있습니다.

9.4 그룹

2개 이상을 선택하고 그룹(Ctrl+G)을 누르면 하나의 새 블록으로 묶입니다. 원래 객체는 저장할 때 삭제되고, 묶음은 앞으로 하나의 객체처럼 이동·회전·삭제됩니다.

9.5 격자 스냅

격자를 켜면 이동·복제 위치가 10 단위 격자에 맞춰집니다.

9.6 장비영역 겹침 금지

“장비영역 겹침” 오류이동·회전·복제 결과 다른 장비와 겹치면 오류를 알리고 이전 위치로 되돌립니다. 변 끝이 맞닿는 것은 허용되고, 면적이 겹치면 거부됩니다. 저장 직전에도 한 번 더 검사합니다.

10. 정점 편집

면(폴리곤) 객체 하나를 선택하고 정점을 누르면 꼭짓점 핸들(사각형)과 변의 중점 핸들(원)이 나타납니다.

  • 꼭짓점을 끌면 모양이 바뀝니다. 가까운 다른 꼭짓점에는 자동으로 붙습니다.
  • 중점 핸들을 누르면 그 변에 꼭짓점이 추가됩니다.
  • 꼭짓점을 우클릭하면 삭제됩니다(면은 최소 3개 필요).
제한블록 객체(장비)와 여러 개를 선택한 경우에는 사용할 수 없습니다. 장비는 이동·회전·복제·그룹으로 편집합니다.

11. Undo / Redo / 편집 취소

키 · 버튼동작
Ctrl+Z · 이전Undo: 직전 편집 하나를 되돌립니다. 최대 100단계.
Ctrl+R · 다시Redo: 되돌린 편집을 다시 적용합니다.
Esc편집 취소: 드래그 중이면 그 드래그만 취소, 아니면 저장하지 않은 모든 편집을 버리고 저장된 상태로 돌아갑니다. 버린 내용도 Undo로 되살릴 수 있습니다.
취소모든 변경을 버리고 편집 모드까지 끝냅니다(확인 창이 나옵니다).

Undo/Redo 대상: 이동(마우스·키보드), 회전, 복제, 삭제, 그룹, 정점 편집. 편집 모드에 들어가거나 나올 때, 그리고 저장한 뒤에는 기록이 비워집니다.

12. DXF 내보내기

  1. 툴바 출력(또는 File → Export DXF (blocks)…)을 누릅니다. (drawing.export 권한)
  2. 저장할 파일 이름을 정합니다.
  3. 편집 모드이면 저장 전의 현재 편집 상태가, 조회 모드이면 서버에 저장된 장비가 내보내집니다(숨긴 레이어 제외).

내보낸 DXF의 구조

  • 장비 이름별로 BLOCK 정의가 하나, 장비 하나마다 INSERT가 하나씩 만들어집니다. CAD에서 일반 블록처럼 열립니다.
  • 각 INSERT에는 숨김 블록 속성이 들어 있습니다.
속성 태그값
NAME설비(블록) 이름
ROTATION회전각(도, 반시계 방향이 +)
POS_X / POS_Y위치점(삽입점) 좌표
참고속성은 도면에 글자로 보이지 않으며 CAD의 속성 편집/추출 기능으로 읽을 수 있습니다. 이름이 같은 장비는 모양이 같다고 보고 블록 정의 하나를 공유합니다(수정하지 않은 장비의 모양 기준).

13. 블록 라이브러리

자주 쓰는 장비 모양을 라이브러리에 등록해 분류·검색하며 관리합니다. 툴바 블록으로 라이브러리 창을 엽니다.

  • 자동 등록: DXF를 입력하면 블록 이름별로 항목이 만들어지고, 도면의 장비와 연결됩니다.
  • 직접 등록: 장비를 선택하고 등록. 같은 모양이 이미 있으면 새로 만들지 않고 연결합니다.
  • 라이브러리 창: 왼쪽에 분류 트리, 위에 검색(코드·이름·제조사·모델)과 상태 필터, 가운데 썸네일 목록, 오른쪽에 미리보기와 속성. 분류 추가·이름 변경, 항목 편집·삭제가 가능합니다.
  • 사용 중인 항목은 삭제되지 않고 deprecated(사용 중지)로 바꾸라고 안내합니다.
[ 화면 캡처 6 자리 ]

19. 도면과 버전 관리

설비 배치를 여러 번 고치면서 어떤 안이 있었는지 남기고, 안끼리 비교하고, 이전 안으로 되돌리고, 두 안을 따로 키워 보는 기능입니다. 서버에 저장되므로 모든 사용자가 같은 버전 목록을 봅니다.

용어뜻
도면배치 하나. 도면마다 작업본(지금 편집하는 데이터)과 버전이 따로 있습니다. 처음에는 “기본 도면” 하나뿐입니다.
버전도면의 한 시점을 통째로 저장한 사본. 저장한 뒤에는 바뀌지 않습니다.
확정(baseline)기준으로 정한 버전. 이름 변경·삭제가 막힙니다. 도면당 하나입니다.
분기버전 하나에서 시작하는 새 도면(B안). 원래 도면과 따로 편집·저장됩니다.
화면에서 상태 확인상태 표시줄에 도면: A동 2층 · v5 기반 (수정됨)처럼 표시됩니다. “v5 기반”은 지금 작업본이 v5에서 출발했다는 뜻이고, “(수정됨)”은 그 뒤 바뀌었다는 뜻입니다. 이 글자를 누르면 버전 관리자가 열립니다.

19.1 버전 저장

  1. 편집 중이면 먼저 저장합니다(버전은 서버에 저장된 도면을 담습니다).
  2. 툴바 버전 또는 Ctrl+Shift+S.
  3. 이름(예: “1차 검토안”)과 설명을 적고 Save version.
  • 마지막 버전과 내용이 같으면 새 버전을 만들지 않고 알려 줍니다.
  • 자동 버전: 편집을 저장할 때마다 “자동 저장 날짜시각” 버전이 남습니다(내용이 같으면 건너뜀). 설정 → General에서 끌 수 있고, 버전 관리자에서 “Show automatic versions”로 숨길 수 있습니다.

19.4 도면 관리 (A/B안 동시 작업)

툴바 도면 또는 Version → Drawings…

  • Open(더블클릭): 다른 도면을 엽니다. 그 도면의 작업본이 화면에 나옵니다. (편집 모드에서는 먼저 저장하거나 취소하세요.)
  • New empty drawing…: 비어 있는 새 도면. DXF를 입력해 채울 수 있습니다.
  • Rename… / Delete…: 이름 변경, 삭제(그 도면의 작업본과 모든 버전이 함께 삭제되며 되돌릴 수 없음). 지금 열려 있는 도면과 마지막 도면은 삭제할 수 없습니다.
B안 만들기버전 관리자에서 기준이 될 버전을 고르고 Branch to new drawing… → 이름 입력 → “지금 열까요?”에 예. 이제 A안(원래 도면)과 B안(새 도면)이 서로 영향 없이 따로 편집됩니다. 두 안을 비교하려면 B안의 작업본을 버전으로 저장한 뒤 같은 기준 버전과 각각 비교하세요.
다른 사용자와의 관계변경 알림(“서버 데이터가 변경되었습니다”)은 같은 도면을 열고 있는 사용자에게만 갑니다. 다른 도면에서 작업하는 사람과는 서로 영향이 없습니다.

19.5 처음 접속할 때

데이터베이스 업그레이드이 기능이 들어간 버전으로 처음 로그인하면 서버 데이터베이스가 자동으로 업그레이드됩니다(도면·고유 번호 컬럼과 버전 테이블 추가, 기존 데이터는 “기본 도면”으로 이관). 사용자 화면에는 변화가 없지만, 운영 중인 서버라면 미리 백업해 두세요. 이 버전을 쓰는 모든 사용자가 같은 서버를 쓰면 문제가 없고, 업그레이드 전 버전의 프로그램은 업그레이드된 서버에서 정상 동작을 보장하지 않으므로 함께 교체하세요.

20. 화면 캡처와 도움말

20.1 화면 캡처 (클립보드 복사)

툴바 캡처, Tools → Copy screen to clipboard, 또는 Ctrl+P(Shift를 같이 눌러도 됩니다)를 누르면 프로그램 영역이 이미지로 클립보드에 복사됩니다. 메일·문서·메신저에 Ctrl+V로 붙여 넣으세요.

  • 다이얼로그가 떠 있어도 동작합니다. 메인 창과 열려 있는 다이얼로그·메시지 상자·열린 메뉴가 화면에 보이는 모습 그대로 한 장에 들어갑니다.
  • 복사에 성공하면 상태 표시줄에 크기와 창 개수가 표시됩니다.
  • 이미지가 검게 나오는 환경(일부 원격 접속·가상 화면)에서는 자동으로 다른 방식으로 다시 시도합니다. 마지막 방식에서는 다이얼로그 제목 표시줄이 빠질 수 있습니다.
  • 단축키는 설정 → Shortcuts에서 바꿀 수 있습니다.

20.2 사용자 매뉴얼 보기

F1 또는 Help → User manual (PDF)를 누르면 이 매뉴얼의 PDF 판이 컴퓨터의 기본 PDF 뷰어로 열립니다. 파일은 프로그램 폴더의 Manual\UserManual.pdf이며, 없으면 경고가 표시됩니다.

20.3 프로그램 파일 이름

실행 파일 이름은 OmniDT-SE.exe입니다.

18. 문제 해결

증상 / 메시지원인과 해결
툴바 버튼이 흐리다서버에 연결되지 않았거나, 권한이 없거나, 편집 모드가 아닙니다(Undo·회전·전체 선택 등). 선택한 객체가 없어도 흐립니다.
“Connect to the server and log in first.”서버 연결과 로그인이 먼저 필요합니다(2장).
“Exit edit mode before reloading layers.”편집 중에는 불러오기·새로고침·레이어 삭제·이름 변경을 할 수 없습니다. 저장하거나 취소하세요.
“장비영역 겹침”장비 외곽이 다른 장비와 겹칩니다. 이동·회전·복제는 취소되고 저장도 거부됩니다. 겹치지 않게 옮기세요.
저장 후 “N개 객체가 그 사이 다른 사람에 의해 변경되어 덮어쓰지 않았습니다”충돌입니다. 새로고침으로 최신 상태를 받아 다시 작업하세요.
같은 이름의 레이어 오류 (이름 변경)이미 있는 이름입니다. 다른 이름을 쓰세요.
로그인이 잠김5회 연속 실패 시 15분 잠깁니다. 관리자에게 잠금 해제를 요청하세요.
단축키가 안 먹는다텍스트 입력란에 커서가 있으면 동작하지 않습니다. 지도를 한 번 누른 뒤 다시 시도하세요. 설정 → Shortcuts에서 충돌 여부도 확인하세요.
DXF를 입력했는데 다른 파일이다현재는 data\SmartLayout.dxf로 고정되어 있습니다.
실수로 레이어를 삭제했다복구 기능이 없습니다. DXF를 다시 입력하거나 관리자에게 서버 백업 복원을 요청하세요.
